# 경제 카드뉴스 제작기

제미나이가 쓴 경제 원고(JSON)를 붙여 넣으면 1080x1350 카드뉴스 8장을 만들고 JPG로 저장하는 도구예요. 카드 종류는 두 가지예요.

- **경제 이슈 카드뉴스**: 금리, 물가, 환율 같은 주제 하나의 최근 이슈와 앞으로 나올 발표 일정(지표 발표, 금리 결정 회의 등)
- **경제 트렌드**: 돈과 소비가 어디로 흐르는지, 산업과 시장이 어떤 구조로 움직이는지

카드 머리말에는 회사 로고 없이 `ECONOMY BRIEF / NO.` 같은 글자만 들어가요.

- `card-news-maker.html` 하나만 내려받아 브라우저로 열어도 그대로 동작해요(인터넷 없이도 됨).
- 웹 주소(https)에 올리면 휴대폰과 컴퓨터에 **앱으로 설치**할 수 있어요.

## 앱으로 쓰기

이 저장소의 GitHub Pages에서는 스포츠판 주소 뒤에 `economy/`를 붙인 주소(예: `https://amos5982-droid.github.io/-/economy/`)로 열려요. 스포츠 앱과 따로 설치되고, 기록과 오프라인 저장분도 서로 섞이지 않아요.

1. 이 폴더의 파일을 https 주소로 올려요. 올리는 파일은 아래와 같아요.
   - `card-news-maker.html`, `index.html`, `manifest.webmanifest`, `sw.js`, `icon-192.png`, `icon-512.png`, `icon-maskable-512.png`
   - 쉬운 방법: GitHub Pages(저장소 Settings → Pages → 브랜치 선택) 또는 Netlify Drop(폴더를 끌어다 놓기)
2. 휴대폰에서 그 주소를 열고 설치해요.
   - 아이폰(사파리): 공유 버튼 → "홈 화면에 추가"
   - 안드로이드(크롬): 메뉴 → "앱 설치" 또는 "홈 화면에 추가"
   - 컴퓨터(크롬/엣지): 주소창 오른쪽의 설치 아이콘
3. 한 번 열고 나면 인터넷이 없어도 열려요. 새 버전을 올리면 다음에 열 때 바뀌어요.

휴대폰 앱에서 "JPG 8장 저장"을 누르면 8장을 만든 뒤 "사진에 저장/공유" 버튼이 나와요. 누르면 공유 창이 열리고, "이미지 8개 저장"으로 사진 앱에 한 번에 넣을 수 있어요.

## 제미나이 자동 실행(API 키)

2단계 "제미나이 자동 실행 설정"에 Google AI Studio에서 받은 API 키를 넣으면, 복사와 붙여넣기 없이 버튼 하나로 원고를 받아 카드까지 만들어요.

- **자동으로 만들기**(2단계): 국문 원고를 구글 검색으로 조사해서 써요. 검색 기능이 열린 키(결제 설정)가 필요해요. 무료 키는 검색 한도가 없어 안내 문구가 떠요.
- **영문판 자동 만들기**(3단계): 국문 원고를 영어로 옮겨요. 검색이 필요 없어 무료 키로도 되고, 빠른 모델로 10초 안팎이 걸려요.
- **자동으로 고치기**(3단계 "고칠 것"): 고칠 것을 제미나이에 보내 고친 원고로 다시 만들어요. 설정에서 켜 두면 원고를 받거나 붙여 넣은 뒤 최대 2번까지 알아서 고쳐요. 검색을 못 쓰면 새 숫자를 넣지 않는 조건으로 고쳐요.
- 키는 그 기기의 브라우저(앱)에만 저장되고, 제미나이 API에만 보내요. 저장소나 다른 곳에는 넣지 않아요.

## 진행 순서

화면은 한 단계씩 넘어가요. 카드를 만들면 각 단계 제목 바로 아래에 8장 미리보기가 가로로 나와요. 오른쪽 위 단계 버튼을 누르면 목차가 펼쳐져 원하는 단계로 바로 갈 수 있어요.

1. **주제**: 카드 종류와 주제를 넣어요. 비워 두면 제미나이가 요즘 가장 화제인 주제를 골라요. 지난 호 소재는 발행 기록에서 자동으로 채워져요.
2. **제미나이**: "복사하고 제미나이 열기"로 프롬프트를 보내요. 프롬프트는 직접 고쳐도 돼요.
3. **원고**: 국문/영문 전환 버튼이 있어요. "붙여넣기"를 누르면 제미나이 답변을 붙여 넣고 바로 카드를 만들어요. 고칠 게 있으면 아래 "고칠 것"이 펼쳐지고, 없으면 접혀 있어요. 영문은 "영문"으로 바꾸면 국문 원고가 들어간 영문 프롬프트를 바로 보낼 수 있어요.
4. **발행호**: 호 번호와 발행일이 자동으로 채워져요. 발행 기록도 여기서 봐요.
5. **디자인(선택)**: 참고 이미지로 색을 바꾸거나, 제미나이로 레이아웃과 꾸밈까지 바꿔요.
6. **저장**: JPG 8장을 저장해요. "영문판도 만들기"로 영문판으로 넘어갈 수 있어요.
7. **인스타**: 캡션을 자동으로 써 주고 인스타로 보내요.

7단계에서는 캡션과 해시태그를 자동으로 써 주고, "인스타로 보내기"를 누르면 캡션을 복사한 뒤 휴대폰에서는 공유 창으로 8장을 인스타그램 앱에 넘겨요. 컴퓨터에서는 8장을 내려받고 인스타그램 웹을 열어요. 버튼 하나로 바로 게시되는 완전 자동 업로드는 Meta 그래프 API, 비즈니스 계정, 이미지를 올려 둘 서버가 있어야 해서 아직 넣지 않았어요.

## 발행 기록(지난 호 소재)

- JPG를 저장하면 그 호가 카드 종류(경제 이슈 카드뉴스 / 경제 트렌드)와 언어(국문 / 영문)별로 자동 기록돼요. 국문과 영문은 발행 번호를 따로 매겨요.
- 바로 직전 호가 프롬프트의 `[지난 호 소재]`에 자동으로 들어가고, 다음 호 번호도 기록에서 정해져요.
- 4단계(발행호)의 "발행 기록" 버튼을 누르면 지난 호 번호와 주제가 목록으로 보여요. 잘못된 기록은 ×로 지울 수 있어요.
- 기록은 그 브라우저(또는 그 앱)에만 저장돼요. 예전 스포츠판과는 따로 저장돼요. 다른 기기에서 이어 만들려면 "기록 내보내기"로 받은 파일을 그 기기에서 "기록 가져오기"로 넣으세요.
