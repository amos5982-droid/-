# 도련 + 칼선 만들기 (일러스트레이터 스크립트)

`bleed-cutline.jsx` — 현재 열린 AI 문서에 칼선(마젠타, 레이어 `칼선`)과 3mm 도련을 만든다. 기존 레이어와 개체는 지우거나 합치지 않는다.

## 쓰는 법
1. AI 파일을 연다.
2. 파일 맨 위 `CONFIG`의 `cutSourceLayers`에 칼선과 도련을 딸 레이어 이름을 적는다 (예: 파란 배경 레이어, 흰 테두리 레이어). 비우면 보이는 모든 레이어를 쓴다.
3. 파일 > 스크립트 > 기타 스크립트… > `bleed-cutline.jsx`
4. 끝나면 `원본이름_도련칼선.ai`로 저장된다. 원본 파일은 바뀌지 않는다.

## 도련을 만드는 방식
도련은 칼선 바깥으로 3mm 더 인쇄해 두는 것이다.
- **칼선**: 위 레이어의 아트워크(선수 테두리 + 파란 사각형)를 복제해서 하나의 바깥 윤곽으로 합친다. 안쪽 구멍 선은 지운다.
- **클리핑 마스크 배경**(파란 사각형 등): 마스크 모양을 3mm 바깥으로 키우고, 마스크 전체를 덮던 안쪽 배경 이미지는 키운 마스크를 덮을 만큼 균일 확대한다. 안쪽 글자·로고는 건드리지 않는다.
- **마스크가 아닌 아트워크**(선수 사진의 흰 테두리 등): 윤곽을 3mm 부풀린 흰색 도형을 `도련_흰색` 레이어에 만들어 맨 아래에 둔다. 마스크 배경 위쪽은 배경에 가려지고, 배경 바깥으로 나온 부분만 흰색 도련으로 보인다. 흰색 도형은 선 두께 6mm(양쪽 3mm)의 흰 선으로 만든다.
- 아트보드는 도련이 들어가도록 키운다.

## 설정 (파일 맨 위 `CONFIG`)
`bleedMM`, `cutLayerName`, `cutStrokePt`, `cutOffsetMM`(칼선 안/바깥 간격), `cutSourceLayers`, `whiteBleedLayerName`, `whiteBleedSourceLayers`(흰색 도련으로 부풀릴 레이어. 비우면 `cutSourceLayers`에서 마스크 묶음을 뺀 나머지), `traceImages`(사진 윤곽 추적), `removeInnerHoles`, `outlineStrokes`(선 두께까지 윤곽에 포함, 실험적), `saveCopy`.

## 한계
- 사진 윤곽 추적은 투명 배경(알파)이 있는 이미지를 전제로 한다. 흰색 도형(벡터)으로 된 테두리 레이어가 있으면 그걸 쓰는 편이 정확하고 빠르다.
- 마스크 안 배경 이미지는 균일 확대로 도련을 채운다. 복잡한 사진이면 가장자리가 어색할 수 있으니 눈으로 확인한다.
- 마스크 모양이 사각형이 아니면(모서리 깎임 등) 가장자리에 닿은 점만 바깥으로 옮기므로 모양이 약간 달라질 수 있다.
- 흰색 도련 도형은 맨 아래 레이어에 둔다. 마스크 배경보다 아래에 있는 불투명 배경이 따로 있으면 그 아래에 깔린다.
- 글자·심볼·메시는 도련으로 늘리지 않는다.
- 일러스트레이터가 없는 환경에서 작성해 문법만 검사했고 실제 실행은 해보지 못했다. 처음엔 복사본 파일로 시험할 것.
