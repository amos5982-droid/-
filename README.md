# 스포츠 카드뉴스 제작기

제미나이가 쓴 원고(JSON)를 붙여 넣으면 1080x1350 카드뉴스 8장을 만들고 JPG로 저장하는 도구예요.

- `card-news-maker.html` 하나만 내려받아 브라우저로 열어도 그대로 동작해요(인터넷 없이도 됨).
- 웹 주소(https)에 올리면 휴대폰과 컴퓨터에 **앱으로 설치**할 수 있어요.

## 앱으로 쓰기

1. 이 폴더의 파일을 https 주소로 올려요. 올리는 파일은 아래와 같아요.
   - `card-news-maker.html`, `index.html`, `manifest.webmanifest`, `sw.js`, `icon-192.png`, `icon-512.png`, `icon-maskable-512.png`
   - 쉬운 방법: GitHub Pages(저장소 Settings → Pages → 브랜치 선택) 또는 Netlify Drop(폴더를 끌어다 놓기)
2. 휴대폰에서 그 주소를 열고 설치해요.
   - 아이폰(사파리): 공유 버튼 → "홈 화면에 추가"
   - 안드로이드(크롬): 메뉴 → "앱 설치" 또는 "홈 화면에 추가"
   - 컴퓨터(크롬/엣지): 주소창 오른쪽의 설치 아이콘
3. 한 번 열고 나면 인터넷이 없어도 열려요. 새 버전을 올리면 다음에 열 때 바뀌어요.

휴대폰 앱에서 "JPG 8장 저장"을 누르면 8장을 만든 뒤 "사진에 저장/공유" 버튼이 나와요. 누르면 공유 창이 열리고, "이미지 8개 저장"으로 사진 앱에 한 번에 넣을 수 있어요.

## 발행 기록(지난 호 소재)

- JPG를 저장하면 그 호가 카드 종류(종목 카드뉴스 / 비즈니스 트렌드)별로 자동 기록돼요.
- 바로 직전 호가 프롬프트의 `[지난 호 소재]`에 자동으로 들어가고, 다음 호 번호도 기록에서 정해져요.
- 1번 단계의 "발행 기록" 버튼을 누르면 지난 호 번호와 주제가 목록으로 보여요. 잘못된 기록은 ×로 지울 수 있어요.
- 기록은 그 브라우저(또는 그 앱)에만 저장돼요. 다른 기기에서 이어 만들려면 "기록 내보내기"로 받은 파일을 그 기기에서 "기록 가져오기"로 넣으세요.
